**Example Kit <version>**

A complete, valid Pinman **kit** for a *fictional* portable utility — the authoring
scaffold. Every file is annotated. It uses only stock adapters (pure data, no custom
code), so it's the reference for building your own kit.

> Scaffold/example content for kit authors — it tracks a fictional app, not real
> software.

### Install

1. Download `example-kit-<version>.zip` below.
2. `pinman kit install example-kit-<version>.zip --add`

This makes the kit resolvable on your machine and adds it to the active project.

### What is a kit?

A kit teaches Pinman the files and settings that matter for a particular software
ecosystem — schemas, profiles, and guidance — packaged for install. See
[pinmantech.com](https://pinmantech.com) for the kit-authoring guide.

### Requirements

- Pinman 2 (any tier)
