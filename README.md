> The official download and support home for **Pinman**.

> 🚧 **Setting up:** this repository is Pinman's new download and support home,
> going live alongside the **Pinman Operator 1.3** release (expected late July
> 2026). Until then some links — the website at
> [pinmantech.com](https://pinmantech.com) and the Releases page — are still
> filling in.

Pinman is closed-source software by [Parkerhill Technology Corp](https://parkerhill.com).
This repository does **not** contain source code — it exists to distribute releases
and to track bug reports and feature requests.

📖 **Website & documentation:** [pinmantech.com](https://pinmantech.com)

There are two Pinman applications:

- **Pinman Operator** — free remote control for the PC behind the screen. Available now.
- **Pinman 2** — capture, compare, and manage the files and settings that configure a
  machine. Includes the Operator controls. Currently in **closed beta**.

for release history.

1. Go to [Releases](../../releases/latest).
2. Download the `Pinman-Operator-Setup-x.y.exe` installer asset.
3. Run the installer and follow the prompts.

> **Windows SmartScreen note:** if you see a "Windows protected your PC" warning,
> click **More info → Run anyway**. This appears for installers that aren't yet
> widely downloaded.

## Support & bug reports

- 🐞 **Found a bug?** [Open an issue](../../issues/new/choose) — there are separate
  templates for Pinman Operator and the Pinman 2 beta.
- 🔎 Browse existing reports:
  [Operator issues](../../issues?q=is%3Aissue+is%3Aopen+label%3Aoperator) ·
  [Pinman 2 beta issues](../../issues?q=is%3Aissue+is%3Aopen+label%3Apinman2)
- 💬 **Question or need help?** Check [Discussions](../../discussions) or see
  [SUPPORT.md](SUPPORT.md).
- 📝 **Release history:** see the [CHANGELOG](CHANGELOG.md).

> **This is a public issue tracker.** Please don't include private or proprietary
> information in reports. If a detail matters but can't be public, omit it and email
> it to <jonathan@pinmantech.com>, mentioning the issue number.

Please include your Pinman version and Windows version when reporting a problem.
