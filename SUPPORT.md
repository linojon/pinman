# Getting support for Pinman

Thanks for using Pinman! Here's how to get help.

## I have a question or need help using Pinman

- Browse or start a thread in **[Discussions](../../discussions)**.
- Check the [documentation](https://pinmantech.com), [README](README.md), and
  [CHANGELOG](CHANGELOG.md) first — your question may already be answered.

## I found a bug

Please **[open an issue](../../issues/new/choose)** and pick the matching template.

A good report includes:

- **Version** (shown in the app's About screen / installer filename)
- **Windows version** (e.g. Windows 11 23H2, 64-bit)
- **What you did**, what you expected, and what actually happened
- Steps to reproduce, plus screenshots or error messages if you have them

> **This issue tracker is public.** Anyone on the internet can read what you post.
> Please leave private or proprietary information out of reports, screenshots, and
> logs. If a detail matters to the bug but can't be public, omit it from the issue
> and email it to <jonathan@pinmantech.com>, mentioning the issue number.

## Pinman 2 beta

The Pinman 2 closed beta is invite-only — testers receive builds and download links
by email. Not a tester yet? [Apply here](https://pinmantech.com/beta).

## Note on source code

Pinman is closed source. This repository is for **downloads and support only** —
it does not contain the application's source code, and code contributions are
not accepted. Documentation fixes and bug reports are very welcome.
